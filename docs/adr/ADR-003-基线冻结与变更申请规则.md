# ADR-003：基线冻结与变更申请规则（T10）

- 状态：已接受
- 日期：2026-11-14
- 决策人：陈欣然（角色1）

## 背景

规格书 4.2 与《产品开发流程》阶段 6 要求：三方会签全绿后方可冻结基线；
冻结后黑板进入"只读 + 变更申请"状态；变更须"请求 → 影响评估 → 审批 → 版本更新 → 通知干系人"。

## 决策

1. **冻结前置校验**：业务 / 开发 / 测试三方 Signoff 必须全部 `APPROVED`（缺一方返回 B102，未全绿返回 B103 并提示升级 PM 催办）；
2. **版本规则**：首次冻结 `V1.0`；此后每次变更批准小版本 +1（`V1.0 → V1.1`），大版本升级由人工决定；
3. **只读拦截**：冻结项目 ID 记入 `blackboard_readonly`，任何黑板写入前必须调用 `assert_blackboard_writable`（失败返回 B301）；
4. **变更申请**：提交时必须带描述；影响评估（范围/成本/工期）字段可空但建议填写；审批通过自动更新基线版本并通知 PM/业务/开发/测试。

## 后果

- T2 黑板服务写入接口必须集成 `assert_blackboard_writable` 拦截；
- 前端确认页、变更申请页依据 B301/B102/B103 错误码做红点与告警展示。
